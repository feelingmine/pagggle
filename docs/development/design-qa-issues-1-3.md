## 实际操作检查

- #1：3 条原始英文引文默认折叠，整体开关展开 3 条完整引用及来源区；逐字对应保存内容。已选“需要修改”时切换原文，表单选择仍保留。手机展开不溢出。没有翻译原文或调用模型。
- #2：市场 8 个选项、语言 9 个选项；默认中东/英语。“其它”显示必填具体值，空值无法提交；返回修改保留输入。逐行市场/语言优先有接口回归覆盖。
- #3：首次只显示关键词导入；7 条 CSV 输入对账为 5 条有效、1 条重复、1 条错误。确认导入后进入分析步骤，点击分析全部关键词才执行本地引擎；5 词形成 3 个候选组，没有按 UI 筛选缩减输入。
- 检索非主关键词 custom silicone 可命中 silicone gasket 组；选择当前结果后保留 1 组，切换至无结果状态仍保留选择。零选择时完成按钮禁用；显式空选择服务端回归通过。
- 保存筛选后进入持续补充页面，解锁客户问题与产品变化；刷新后完成状态保留。客户问题与产品变化分别通过预览、保存，整段作为一条需求，搜索量/KD 保持未知。
- 切换到未完成的合成项目，返回首次导入，恢复中东/英语默认值，不继承完成状态和新增入口。
- 修正浏览器中发现的含混文案：完成聚类后的内容需求列表使用“待识别意图”，避免被理解为首次分析未完成。
- Chrome 控制台检查未发现 error/warn。合成验证服务使用独立 data/verification 数据库和已缓存的本地向量模型；未触发真实站点采集、在线模型、意图识别或内容生成。

首次保存是后续研究候选，不等同于正式页面审批或生成内容。尚未保存的选择保留在当前页面会话，切换项目会提醒，刷新会触发离开提示；确认离开后草稿不持久化，已保存结果持久化。Chrome 切换移动设备模式曾触发重载及离开提示，重新选择后完成验证，未把草稿当作已保存结果。浏览器 E2E 使用 CSV；XLSX 解析沿用现有回归覆盖，本轮未重新进行浏览器文件上传。
