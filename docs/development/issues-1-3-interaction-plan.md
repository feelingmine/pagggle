# Issues 1–3：交互与验收方案

来源：[业务理解原文 #1](https://github.com/feelingmine/pagggle/issues/1)、[市场与语言 #2](https://github.com/feelingmine/pagggle/issues/2)、[首次需求旅程 #3](https://github.com/feelingmine/pagggle/issues/3)。2026-10-09 读取正文及评论（无补充评论）。这些是用户新增的操作要求，PRD 原件不改。

沿用已选定的第二版视觉：浅色背景、文档式阅读、橙色强调、克制的表格与步骤提示。改动现有业务理解、导入和聚类页面，不重建应用或增加独立产品首页。

## 1. 中文业务理解与网站原文

中文主张、适用范围和核对操作保持为主要阅读内容。每条主张下提供默认折叠的“网站原文”，展示已保存的精确引用及完整来源入口；页面提供“显示/收起网站原文”开关。原文不翻译、不截断、不调用模型；支持多个来源，历史版本使用自己的引用。新项目恢复默认折叠。

验收：默认无展开的英文引文；单条展开和整体开关可用；正文与既有引用逐字一致；展开后仍能核对、修改、查看历史；移动端长文本不溢出。

## 2. 市场与语言下拉框

> 后续用户要求参考 Semrush，并取消市场预选；最新实现以 [国家/地区与语言口径](semrush-market-language.md) 为准。以下保留首次 issue 验收依据。

市场选项依次为中东、东南亚、欧洲、北美、南美、非洲、东亚、其它，默认中东。语言选项依次为英语、俄语、德语、西班牙语、法语、汉语、日语、韩语、其它，默认英语。选“其它”展示必填具体内容输入；表格逐行已有市场/语言优先，表单值只补空白，不覆盖原值。语言使用稳定代码（如 en），市场保留选项名称。默认值是用户可修改的导入范围，不是网站事实或自动推断。

验收：默认值、全部选项、其它必填、返回修改保留值；CSV/XLSX 逐行值优先；切换项目不沿用上一项目的输入。

## 3. 首次关键词主流程

进入内容需求时，尚未完成首次分析的项目只呈现：导入关键词 → 分析全部有效关键词 → 筛选候选结果 → 确认完成。首次导入页不显示客户问题/产品变化标签或独立意图识别分支。导入预览保留有效、重复、失败对账；无有效输入时留在导入，支持修正及分批补齐。确认导入后进入分析页，由用户点击一次“分析全部关键词”，复用现有本地聚类引擎。

结果可按关键词（含组内成员）和待核对状态筛选，可选候选组并保存首次筛选结果；允许明确选择暂不保留任何组。只有成功且覆盖当前项目全部有效关键词的结果版本才能完成；新增输入、未完成任务、旧/部分结果和跨项目记录不能绕过。重复与导入失败记录保留，可在同一流程中查看，不被当作成功分析。完成不等同于确认正式页面计划，也不自动批准业务理解。

首次完成状态及所选候选组绑定项目和结果版本，在数据库保存。完成后进入内容需求列表，显示补充关键词、添加客户问题、记录产品变化入口；后两者以单条原始内容保存，继续沿用现有意图能力。内容生成仍属于后续阶段，本次不冒充已完成 M2。

验收：空项目/已有关键词项目路由正确；刷新可恢复步骤；筛选不会缩减分析输入；先分析后完成的服务端约束有效；完成后入口解锁；跨项目状态隔离；旧资料和旧聚类版本保留。

## 分步验证与提交

1. 阅读体验及导入字段：语法检查与交互检查，通过后独立提交。
2. 首次流程和持久化：接口、全量覆盖、过期/跨项目/重复完成回归，以及前端状态回归，通过后提交。
3. 合成项目端到端走查桌面/移动布局；真实项目只迁移结构，不自动分析或改写人工版本。记录实际结果与限制，再推送开发分支。浏览器工具不可用时明确记录视觉验收阻塞，不以接口成功代替。

### 第一步实测

已实现 #1/#2。Node 渲染状态回归 2 项通过，JS 语法与 diff 检查通过。用户授权使用 Chrome 后，在独立 8001 服务/合成库验证：3 条英文引用默认折叠，整体展开后逐字展示保存的原文且无横向溢出；市场 8 项、语言 9 项，默认中东/英语；“其它”展开必填框，空值不通过 HTML 校验；单条关键词可进入导入预览。浏览器走查未调用模型、未写入真实项目。移动端及首次关键词完整流程在下一步继续验收。

### 第二步实测

已实现 #3 的首次导入、全量分析、候选筛选及增量入口。服务端保存完成状态时使用事务，校验最新成功结果、全部有效关键词覆盖、无活动任务、候选归属；再次提交同一选择幂等，旧快照不可覆盖。客户问题和产品变化的预览与导入接口同样检查首次完成状态。

后端全量 94 passed（2 条既有依赖弃用提示），前端 Node 回归 4 passed。Chrome 在独立合成项目实际运行本地语义聚类：7 条输入 → 5 条有效/1 条重复/1 条错误 → 3 个候选组；检索次关键词、状态无结果、筛选后保留选择、保存 1 个候选、刷新恢复完成状态均通过。随后客户问题及产品变化各保存 1 条，多行原文与未知指标保留；另一项目仍处于首次导入。未调用在线模型、采集或真实项目分析。视觉与浏览器详情见 [设计 QA](design-qa-issues-1-3.md)。
