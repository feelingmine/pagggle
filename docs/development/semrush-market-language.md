# 国家/地区与语言：Semrush 口径

2026-10-09，用户要求参考 Semrush 数据库，并明确选择“国家/地区不预选，导入时选择”。本调整替代 issue #2 初版的地域大区列表；PRD 原件与历史记录不改。

## 已核对的口径

- [Keyword Magic Tool 官方使用说明](https://www.semrush.com/kb/617-keyword-magic-tool-manual)：先选择国家数据库，语言是在同一国家数据库内的独立筛选维度。
- [SEO API v3 数据库清单](https://developer.semrush.com/api/v3/seo/overview/#databases)：本次从公开列表提取 research types 包含 Keywords 的 121 个两字母数据库代码；排除 mobile-* 和 *-ext。英国代码使用 uk。中文展示名由对应区域名本地化；英文名称用于检索。
- [可用数据说明](https://developer.semrush.com/api/v4/introduction/available-data/)：不同 API/工具的数据覆盖可能不同。因此这 121 项是本次核实的 SEO 关键词数据库清单，不宣称覆盖 Semrush 所有工具的全部地区，也不是实时同步目录。

官方手册未提供完整固定语言可用性矩阵。本地提供 32 个常用语种及“其它语言”，保留原有英语默认值；新增阿拉伯语、葡萄牙语、意大利语、荷兰语、土耳其语及东南亚常用语种等。它们是 Pagggle 的输入选项，不宣称每个语种都在每个 Semrush 数据库拥有数据，不按国家自动覆盖语言。

## 交互与兼容

当前交互（07e467c）：只保留一个“国家/地区数据库”搜索选择框，支持中文名、英文名和代码，默认留空。点击候选或用方向键/回车选择，Escape 或失焦收起列表；输入尚未匹配完整选项时清除旧国家提交值，避免搜索新国家却提交旧值。无合适选项时可选择其它国家/地区并手动填写，手填内容不宣称属于 Semrush 官方数据库。语言仍独立选择。新交互验证及限制见 [review](review-2026-10-09.md)。

新增导入将选定市场保存为官方数据库代码（如 sa、uk），语言为独立代码（如 en、ar）。CSV/XLSX 各行已有 market/language 仍优先，未重写原值、指纹或历史记录；历史“中东”等值不推断成沙特或阿联酋。查看候选组时，已知代码显示中文名及代码。无需数据库迁移、无需新增配置、未接入 Semrush 付费 API。
