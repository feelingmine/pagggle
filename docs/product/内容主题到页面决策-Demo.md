# 内容主题到页面决策 Demo（2026-10-09）

本补充由用户重新描述的业务需求授权，不覆盖原 PRD。目标是从已有网站、基础词、三份 Semrush 导出与指定竞品，连续得到可复核的内容决策和交付清单。

## 固定业务流

1. 确认输入：显示基础词、选定文件、目标市场/语言、本站资料覆盖与竞品；冻结文件哈希、资料快照和规则版本。
2. 整理与衍生：全量读取所选词表，按词和市场语言归并，保留每个原始观察与异常。基础词派生的未测量短语单独显示，不伪造指标、不混进实测词数。
3. 内容主题：产品对象 × 客户任务形成稳定主题，保留采购、选型、使用、材料证据等边界。渠道导航、不同受众及无明确业务支持的词单独对账，不能消失。
4. 机会与本站匹配：业务适配/任务价值/源表需求证据分别说明；比较 URL 清单及已读正文，区分保留、优化、新增候选、待核对。已有但未读取的相似页面不能直接判定需要新页。
5. 交付：每个优化项有目标 URL、原文覆盖、缺口和修改方向；每个新增候选有对象/任务/目标词/模块大纲/需补证据/内链与行动入口。结果可检索、查看成员和导出。

## 确定性与证据

- 第一个 Demo 使用显式版本化的产品别名、任务规则、页面覆盖规则和大纲结构，借鉴 content-strategy 的业务/客户任务/内容适配方法。规则不是行业普适真值，界面显示判断理由。
- 同一输入快照和规则版本可离线重放，输出规范化哈希一致。新网站内容、文件或规则产生新版本；外部网络不属于重放依赖。
- 本站原有画像、来源和人工基础词修订保持不变。补读与竞品内容独立按项目缓存，不混入本站事实；竞品的认证、产能与工艺不能变成本企业承诺。
- 未知 KD、冲突指标、未测量衍生词和采集失败保持可见。语义/规则主题尚非 SERP 确认同页关系；新增是候选，不直接创建 URL 或发布。
- 不靠多轮聊天保存流程。界面显示运行阶段、失败/取消、历史运行、重放与结果；刷新可恢复。

## 验收

使用用户指定的真实文件和现有站点项目；全输入可对账，跨文件重复不丢来源；存在优化建议与新增候选大纲；相似未读 URL 阻止武断新建；同快照重放结果一致；跨项目结果不可读取；取消/失败不产生完整成功结果；现有资料和人工修改不被覆盖。
