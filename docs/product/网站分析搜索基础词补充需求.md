# 网站分析：搜索基础词（2026-10-09 补充需求）

依据用户追加要求：从网站分析中提取产品和服务分类关键词，用作搜索拓词的行业通用大词。本补充关联 PRD V1.0 的 FR02 网站理解与 FR03 关键词输入，不改动原 PRD 文件，也不改变现有聚类与页面规划规则。

## 操作路径

已有网站业务理解 → 查看“搜索基础词” → 点击提取 → 分别核对产品分类与服务分类 → 查看原文依据 → 复制单词或全部词表 → 在关键词工具搜索拓词 → 按原流程导入真实关键词数据。

## 范围和验收

- 基础词是行业通用类别，不是品牌、型号、颜色尺寸、认证、营销描述或完整服务清单；保留定义类别必需的材料及服务对象。并列的独立产品类别分别输出，服务流程不自动成为对外服务类别。
- 分类说明用中文，搜索词沿用网站主要语言。无需先获得搜索量或 KD，不生成未知指标，不自动导入为待分析关键词，也不创建页面。
- 已分析的网站复用当前业务理解与已保存网页依据，不重新采集或覆盖画像。提取由页面操作发起，刷新只读取既有结果。
- 每词关联本版业务主张与原始网页引用。未确认、推断和冲突主张暂不纳入；结果仍需核对，不能当作企业业务范围的自动确认。
- 发送模型的上下文限定为同站已保存网页的引用、URL 和分类索引，不发送人工修订说明、私有补充资料、关键词表或配置。
- 基础词按项目和业务理解版本保存。失败或取消保留旧结果，业务理解更新后需显式提取对应新版，历史依据不能混用。
- 单词与全部词表可复制，全部词表每行一个词；浏览器拒绝剪贴板写入时提供可手动复制的词表。
